# Buldee

Upload a construction job's files and Buldee runs the right tool on them (Take Off, Estimate, Schedule, Daily Log, Purchase), returning one Excel file built on the Buldee Estimate Template.

## Status

- `prototype/index.html` is the clickable prototype (single HTML file). Runs are simulated; the Excel downloads are built in the browser with ExcelJS.
- Next: the real site (Vercel) with the skills running on Anthropic Managed Agents. See the setup plan in the project.
