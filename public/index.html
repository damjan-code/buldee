    How the real site would work

    1. Upload. Drop up to 4 files, or paste a Google Drive or Dropbox link.
    2. Sort. Claude reads each file's title block, first pages and sheet names and labels it: drawings, specs, addenda, bid form, takeoff, estimate, schedule, photos or field notes. Labels can be corrected.
    3. Pick tools. Rules decide which of your skills can run on what's there, and in what order (takeoff → estimate → schedule). You confirm or override.
    4. Run and download. Each chosen tool runs as a Claude session with your files. Its questions (markup %, start date, crew counts) show up on the page. Buldee then makes one Excel file for the project, with a tab for each tool and your letterhead at the top, ready to download.
